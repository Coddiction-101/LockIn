# Frontend Development — Complete Learning Roadmap

**Goal:** Learn HTML, CSS and JavaScript from scratch, develop strong fundamentals, and become capable of building real-world websites independently.

**Learning approach:** Hands-on, concept-by-concept, practical exercises, mini-projects and gradual integration of technologies.

## 05. Learning Rules

1. Learn one concept at a time.
2. Understand before memorizing.
3. Write code independently.
4. Never blindly copy solutions.
5. Practice every important concept.
6. Debug errors instead of avoiding them.
7. Revisit concepts when necessary.
8. Build small projects throughout the journey.
9. Do not rush through topics to finish the syllabus.
10. Move forward only when the fundamentals are clear.

**Completion strategy:**
- HTML first → introduce CSS around 80% HTML completion.
- Continue HTML + CSS together.
- Introduce JavaScript around 80% CSS completion.
- Continue all three technologies together.
- Finish with integrated projects and independent practice.

**Final goal:** Become confident enough to build a complete responsive and interactive website from scratch without depending on tutorials or blindly copying code.
